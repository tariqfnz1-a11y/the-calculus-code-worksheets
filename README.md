# Printing Instructions

For the best experience:

1. Download the desired worksheet.
2. Open it using Adobe Acrobat Reader.
3. Print on A4 paper.
4. Select **Actual Size (100%)**.
5. Print in Portrait orientation unless otherwise indicated.
